# 项目扩展

## 数据工程

- data_pipeline: 数据流水线

  - 数据划分模式：
    - 负责检查数据是否已划分，若未划分，按项目默认流水线进行数据集转换->划分；若已经划分，则只进行数据集转换，不进行划分
  - 数据划分策略：
    - 支持更多的划分策略
  - 划分后做一个数据指纹，记录到yaml里面，或者做一个csv文件

- 质检系统

  - 扩展点1：数据输出记录的更加详细，有问题的数据可以记录到csv中，并给出修复建议
  - 扩展点2：质检报告，支持HTML, Word格式
  - 扩展点3：支持更多的检测项

## 模型训练

- 6-训练系统：

  - 扩展点1：训练报告：谁什么时间，在那份数据上，数据质量怎么样，做的训练，训练的结果怎么样？

- 7-模型评估系统:

  - 基础功能：在test数据上评估模型的表现
  - 扩展点：多个模型评估

## 推理与终端

- 8-推理系统

  - 8-1：帧源捕获模块
    - 修复点1：采用注册表+自动注册机制
    - 修复点2：对于视频,间隔帧似乎没有生效，每隔2帧或者指定帧采集一次

- 其他扩展点1：需要完成的

  - 完成桌面端：pyqt5, pyside6

## 项目基础工具与AI接口

- 将项目扩展为智能体： 将各种输出报告（如数据划分、质检报告、训练报告等）通过api转为md/html

- 项目重置工具：

  - 功能项：系统重置的时候，可以选择将上一个项目核心文件进行打包备份
