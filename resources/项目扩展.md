# 项目扩展

- 1-项目初始化：核心搭建底层基础设施

  - 路径管理工具：`paths.py`
  - 日志工具：`logging_utils.py`: 其中关于临时名称这一部分可以优化
  - 性能记录工具:`performance_utils.py`
  - 初始化脚本：`init_project.py`

- 2-项目重置工具：

  - 功能项：系统重置的时候，可以选择将上一个项目核心文件进行打包备份

- 3-data_pipeline: 数据流水线

  - 数据的转换：
    - 支持更多的格式
  - 数据的划分：
    - 支持更多的划分方式
  - 数据的落盘
    - 像我们一样，实实在在的划分到指定的目录里面
    - 我们可以把文件名字指向到一个txt当中，做链接引用
  - 以及`yaml`生成
  - 扩展项：划分后做一个数据指纹， 记录到yaml里面，或者做一个csv文件！

- 4-质检系统

  - 扩展点1：支持更多的检测项
  - 扩展点2：支持重型检测Phash
  - 未来扩展点：做多线程检测
  - 扩展点3：数据输出记录的更加详细，有问题的数据可以记录到csv中，并给出修复建议
  - 扩展点4：质检报告，支持HTML, Word格式

- 5-配置系统

- 6-训练系统：

  - 修复点1：日志归档，模型归档这些，采用提前预设名称，这样可以减少很多繁琐操作
  - 扩展点1：训练报告：谁什么时间，在那份数据上，数据质量怎么样，做的训练，训练的结果怎么样？
  - 修复点2：服务的编排，存在部分业务逻辑，需要优化

- 7-模型评估系统: 

  - 基础功能：在test数据上评估模型的表现
  - 扩展点：多个模型评估

- 8-推理系统

  - 8-1：帧源捕获模块
    - 修复点1：采用注册表+自动注册机制
    - 扩展点1： 如何让他支持深度相机，红外相机
    - 修复点2：对于视频,间隔帧似乎没有生效，每隔2帧或者指定帧采集一次
    - 扩展点2：给这个做异步，或者线程版本
  - 8-2：美化模块
    - 修复点1：目前仅仅支持目标检测任务，扩展很不友好
  - 8-3：4级推理流水线
    - 致命bug: 对mac平台极其不友好，主要原因是显示这部分，在mac上必须挂到主线程，目前我们的项目主线程是推理模块，mac没法用，这部分需要修复
    - 服务的编排，存在部分业务逻辑，需要优化

- 其他扩展点1：需要完成的

  - 完成桌面端：pyqt5, pyside6
  - 完成web端：
    - streamlit, nicegui
    - 传统方法：前端 Vue / React 后端：Django / Fastapi / Flask 
    - 可以在一定程度上接入大模型API, 针对检测的结果提供一定的建议

- 其他扩展点2： 未来可以完成的

  - 将项目扩展未智能体： 目前项目提供CLI接口非常丰富，因此这一点做扩展很容易
