## 三、训练报告 — 实现细节

**触发方式**：`odp-train` 训练完成后自动生成，无需手动操作。

**训练报告完整要素**：

```markdown
# 训练报告 — {实验名}

## 基本信息 — 训练人 / 开始时间 / 结束时间 / 总耗时 / 任务类型 / 状态
## 运行环境 — OS / CPU / Python / PyTorch / Ultralytics / GPU
## 数据集 — 名称 / 路径 / 数据质量引用
## 训练配置 — 关键超参表格 + od_audit.json 引用
## 训练结果 — mAP@50 / mAP@50-95 / Precision / Recall / Fitness
## 训练可视化 — 10 张图（训练曲线 / PR 曲线 / F1 曲线 / 混淆矩阵 / 标签分布 / 批次预览 / 预测对比）
## 产出文件 — 权重 / 审计快照 / 日志
```

**HTML 报告额外特性**：
- 渐变蓝色 Hero 头部 + SVG 背景纹理
- 关键指标仪表盘卡片（hover 上浮动画）
- 根据指标高低自动着色（绿/橙/红）
- 训练配置从 od_audit.json 自动提取填充
- 响应式布局（桌面 + 移动端）
- 零外部依赖，纯本地字符串拼接生成

## 四、模型评估系统 — 实现细节

### ValService 流程

```
build_val_config() → resolve_model_path() → YOLO model.val()
→ 提取指标（复用 TrainMetrics）→ 写入 od_eval_audit.json → 生成 Markdown + HTML 报告
```

### 多模型对比

- **终端输出**：ANSI 彩色表格，每列最优值用绿色 ▲ 标记
- **Markdown 报告**：对比表格 + 自动生成结论（每个模型的优势指标）
- **实现**：`compare_models()` 函数，对每个模型逐一调用 ValService.evaluate() 后汇总对比

## 五、实际训练验证

用 fire 火灾数据集完成了 3 次训练 + 3 次评估 + 2 次多模型对比，全部验证通过：

| 实验 | 配置 | val mAP50 | val mAP50-95 |
|------|------|:---:|:---:|
| 原始版 | AdamW / lr0=0.01 / 1 epoch | 0.342 | 0.153 |
| 失败版 | SGD / lr0=0.001 / 1 epoch | 0.088 | 0.042 |
| **优化版** | **AdamW / lr0=0.002 / 10 epochs** | **0.689** | **0.414** |

优化版相比原版 **mAP50 提升 101%**（0.342 → 0.689），验证了 AdamW + 低 lr + 多 epoch 的方向正确。

三模型对比（test 分片）：

| 模型 | mAP@50 | mAP@50-95 | Precision | Recall |
|------|:---:|:---:|:---:|:---:|
| 原始版 1epoch | 0.420 | 0.189 | 0.508 | 0.512 |
| 失败版 SGD | 0.123 | 0.057 | 0.774 | 0.014 |
| **优化版 10epoch ▲** | **0.674** | **0.393** | **0.752** | **0.518** |

## 六、训练参数优化建议总结

基于实际验证得出的最佳配置（YOLO11n + fire 数据集）：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| optimizer | AdamW | 自适应优化器，小数据集表现更好 |
| lr0 | 0.002 | 比默认 0.01 更稳定 |
| epochs | 100 | 当前 10 epoch 已有明显收敛趋势，加满到 100 效果会更好 |
| batch | 16（GPU） | GPU 训练推荐 |
| device | GPU | RTX 4060 8GB 可用，速度提升 20-50 倍 |
| imgsz | 640 | 火焰检测不需要超高分辨率 |

## 八、关键设计决策

1. **Markdown + HTML 双输出** — Markdown 给 Git 版本管理，HTML 给团队直接浏览器看
2. **不接任何 API** — 所有报告纯本地生成，字符串拼接 + CSS 内嵌，断网也能用
3. **不引入数据库** — 审计快照用 JSON 文件，报告用 Markdown + HTML，一切基于文件系统，但数据结构留好 `to_dict()` 接口
4. **训练后自动评估** — `--auto-eval` 参数可选，训练完成后直接调 ValService 评估 best.pt 并追加到报告
5. **图片自动引用** — 报告生成时检测同目录下是否存在 ultralytics 产出的图片文件，存在则用相对路径引用，不存在则标注"未生成"
6. **复用现有基础设施** — TrainMetrics、build_val_config、resolve_model_path、resolve_dataset_path 全部复用，不重复造轮子
