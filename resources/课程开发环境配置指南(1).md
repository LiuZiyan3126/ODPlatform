## 二、Miniconda 安装与配置

### 2.1 它是什么 / 为什么用它

Miniconda 是 Anaconda 的精简版，只包含 `conda`（包与环境管理器）和 Python，体积小、干净。我们用它来**为每门课/每个项目创建独立的 Python 环境**，避免不同项目之间的依赖互相污染。

> 如果你之前已经装过 **Anaconda**，则无需再装 Miniconda，直接跳到 §2.4 验证即可——两者的 `conda` 命令通用。

### 2.2 下载

- **官方文档（你也可以从这里进入）：** <https://docs.conda.io/en/latest/>
- **推荐：直接下载安装包（无需注册，速度最快）** —— 打开下面的目录，下载文件名为
  **`Miniconda3-latest-Windows-x86_64.exe`** 的安装包：
  <https://repo.anaconda.com/miniconda/>
- 备选官方下载页（页面内向下滚动可找到 Miniconda 区域，可能需要填写邮箱）：
  <https://www.anaconda.com/download>

> 当前 Miniconda 默认自带的 Python 版本不影响我们使用——后面我们会**单独创建一个 Python 3.12 的环境**。

### 2.3 安装步骤

1. 双击下载好的 `.exe` 安装包。
2. `Welcome` → **Next**；`License Agreement` → **I Agree**。
3. `Select Installation Type`，选择 **Just Me (recommended)** → **Next**。
4. `Choose Install Location`：**请使用纯英文、无空格的路径**，建议保持默认
   `C:\Users\<你的用户名>\miniconda3`（前提是你的 Windows 用户名是英文）。
   若用户名是中文，请改为如 `D:\miniconda3` 这样的路径 → **Next**。
5. `Advanced Installation Options`（**关键一步**）：

   | 选项 | 建议 |
   |---|---|
   | Create shortcuts | ✅ 勾选（默认） |
   | **Add Miniconda3 to my PATH environment variable** | 一般保持**不勾选**（官方默认，更安全）。我们将通过「Anaconda Prompt」使用 conda。若你希望在普通 CMD/PowerShell 里也能直接用 `conda`，可勾选此项 |
   | Register Miniconda3 as my default Python | ✅ 勾选（默认） |
   | Clear the package cache | ✅ 勾选（默认） |

6. 点击 **Install**，等待 1–3 分钟，完成后 **Next** → **Finish**（可取消勾选末尾的推广链接）。

> 建议在第 5 步勾选项页面**截一张图存档**，方便后续排错。

### 2.4 验证安装

从 Windows「开始」菜单搜索并打开 **Anaconda Prompt**（不是普通的 CMD），输入：

```bash
conda --version
```

若显示类似 `conda 24.x.x` 的版本号，即安装成功。再运行 `conda info` 可查看更多信息。

> 若你在第 5 步勾选了「Add to PATH」，则在普通 CMD / PowerShell 里也能运行上述命令。
> 普通终端里报「`conda` 不是内部或外部命令」是正常现象，请改用 **Anaconda Prompt**，或参见文末 FAQ。

### 2.5 （强烈建议）配置国内镜像源加速

国内直接从官方源下载包可能很慢甚至失败。建议配置镜像源。

**① pip 镜像（最常用，先配这个）** —— 在 Anaconda Prompt 中执行：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

**② conda 镜像（可选）** —— 配置方式偶尔会调整，请以清华 TUNA 官方说明为准，按页面内的 `.condarc` 内容操作：
<https://mirrors.tuna.tsinghua.edu.cn/help/anaconda/>

> 校园网 / 公司网络通畅的同学可跳过本节。处于代理或内网环境的同学，镜像或代理设置可能需要联系本单位 IT。
> **注意：** 第四节安装 PyTorch 时会用 `--index-url` 直连 PyTorch 官方仓库，**那一步不走上面的 pip 镜像**（属正常现象）。

### 2.6 合规提示（企业 / 团队环境请留意）

Anaconda 官方默认源（`defaults`）对**员工数 ≥ 200 人的组织**为商用，需购买许可；**个人、学生、教育机构及 200 人以下企业**可免费使用。如在企业环境中无许可，请改用 **conda-forge** 频道或 **Miniforge** 发行版以保证合规。课程学习与个人使用不受此限制。

## 三、创建课程专用虚拟环境（核心步骤，必做）

### 3.1 为什么要单独建环境

把课程依赖装进一个**独立、可随时重建**的环境里，既不会弄乱系统 Python，出问题时也能一键删除重来，互不影响。

### 3.2 创建环境

在 **Anaconda Prompt** 中执行（**环境名 `odplat` 请勿修改**）：

```bash
conda create -n odplat python=3.12
```

执行过程中提示 `Proceed ([y]/n)?` 时，输入 **y** 回车确认（也可在命令末尾加 `-y` 跳过确认）。

### 3.3 激活环境

```bash
conda activate odplat
```

激活成功后，命令行最前面的提示符会从 `(base)` 变为 **`(odplat)`**。
> **重要：** 之后凡是与本课程相关的操作（装包、运行代码），都要先确认前缀是 `(odplat)`。
> 退出环境用 `conda deactivate`。

### 3.4 验证环境

在 `(odplat)` 状态下依次执行：

```bash
python --version
python -c "import sys; print(sys.executable)"
```

- 第一条应显示 **`Python 3.12.x`**；
- 第二条输出的路径中应包含 **`...\envs\odplat\...`**，说明用的确实是 odplat 环境里的 Python。

### 3.5 conda 常用命令速查

| 操作 | 命令 |
|---|---|
| 查看所有环境 | `conda env list` |
| 激活 / 退出环境 | `conda activate odplat` / `conda deactivate` |
| 在当前环境装包 | `conda install 包名` 或 `pip install 包名` |
| 按需求文件批量安装 | `pip install -r requirements.txt` |
| 查看已装包 | `conda list` |
| 删除整个环境（重置时用） | `conda remove -n odplat --all` |

> 如果环境装乱了，删掉后重新执行 §3.2 即可，**不必重装 Miniconda**。

## 四、在 odplat 环境中安装 PyTorch 与 YOLO（必做）

> **重要前提：以下所有命令都必须在已激活 `odplat` 环境的终端中执行**（命令行前缀为 `(odplat)`）。
> 若前缀不是 `(odplat)`，请先执行 `conda activate odplat`。

本课程使用 **PyTorch（CUDA 13.0 版）** 与 **YOLO（ultralytics）**。

> **本课程不在本地跑训练**，训练统一在课程提供的 GPU 服务器上进行。
> 因此**本地环境只需通过「冒烟测试（smoke test）」即可**——也就是 PyTorch、YOLO 能正常导入并打印出版本号。
> **本地有没有 GPU、CUDA 在本地是否可用，都不影响上课。** 没有 N 卡的同学也按下面步骤安装 GPU 版即可，
> 安装会正常完成、冒烟测试也能通过（只是本地用不上 GPU 加速而已）。

### 4.1 安装顺序很重要：先 PyTorch，后 YOLO

> ⚠️ **务必先安装 PyTorch，再安装 ultralytics。**
> 原因：ultralytics 依赖 PyTorch。如果你**先**装 ultralytics，pip 会自动替你装上一个**默认版本的 torch（很可能是 CPU 版，或与课程不一致的 CUDA 版本）**。先把指定版本的 torch 装好，ultralytics 检测到 torch 已满足要求，就不会再替换它。即使你本地没有 N 卡，也请保持「先 torch 后 yolo」的顺序，以保证 torch 版本与课程一致。

正确顺序：

```
① 安装 PyTorch（CUDA 13.0）  →  ② 安装 ultralytics (YOLO)
```

### 4.2 关于显卡：本地有没有 N 卡都能装

- **没有 NVIDIA 显卡也可以照常安装下面的 GPU 版 PyTorch。** 安装会正常完成，只是本地无法调用 GPU 加速——这不影响上课，因为我们不在本地训练。
- **如果你有 NVIDIA 显卡、并且想在本地也用上 GPU 加速**，需满足：
  - 显卡架构为 **Turing 或更新**（大致 GTX 16 系列、RTX 20 / 30 / 40 / 50 系列及更新）；
  - **无需单独下载安装 CUDA Toolkit**——pip 装的 PyTorch 已自带所需 CUDA 运行库，你只需要一个**够新的 NVIDIA 显卡驱动**；
  - 安装 / 更新驱动：<https://www.nvidia.com/Download/index.aspx>（或用 NVIDIA App / GeForce Experience）；
  - 检查驱动：终端执行 `nvidia-smi`，留意右上角 `CUDA Version`，需 **≥ 13.0**（不够就更新驱动）。
- **Mac 用户例外：** macOS 没有 NVIDIA CUDA，**不能**安装 CUDA 版 PyTorch，请改用 §4.5 的方式。

> `nvidia-smi` 右上角的 `CUDA Version` 表示「你的驱动最高支持的 CUDA 版本」，并不代表已经装了 CUDA Toolkit——二者不是一回事，本课程也不需要你单独装 Toolkit。

### 4.3 安装 PyTorch（CUDA 13.0）

官方安装页（可按需选择其他版本）：<https://pytorch.org/>

在 `(odplat)` 环境中执行（**Windows / Linux 通用**；Mac 见 §4.5）：

```bash
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu130
```

> 说明：`--index-url` 只对这一条命令生效，指定从 PyTorch 官方的 CUDA 13.0 仓库下载（因此这步不走清华 pip 镜像，是正常的）。
> 该步骤下载量较大（约数 GB），请保持网络通畅、耐心等待。

**冒烟测试（验证安装是否成功）** —— 执行：

```bash
python -c "import torch; print('torch:', torch.__version__); print('CUDA available:', torch.cuda.is_available())"
```

- 只要能**正常打印出 torch 版本号**、不报 `ImportError`，就说明 PyTorch 安装成功，**即可上课**。
- `CUDA available` 是否为 `True`，取决于你本地有没有可用的 N 卡：
  - **有本地 N 卡** → 应为 `True`（本地可用 GPU 加速）；
  - **没有 N 卡 / Mac** → 为 `False` 属**正常现象**，不影响上课（训练在服务器上进行）。

### 4.4 安装 YOLO（ultralytics）

**确认上一步 PyTorch 已装好**后，再执行：

```bash
pip install ultralytics -U
```

（`-U` 表示安装 / 升级到最新版。）

**冒烟测试（验证 YOLO 环境）** —— 执行：

```bash
yolo checks
```

该命令会打印环境信息，确认 ultralytics 版本、torch 版本是否正常。
> 没有本地 N 卡的同学，`yolo checks` 里显示 CUDA 不可用是**正常的**，不影响上课。

（可选）跑一个最小推理测试，会自动下载一个小模型并对示例图片做检测（无 GPU 时会用 CPU 跑，稍慢但能完成）：

```bash
yolo predict model=yolo11n.pt source='https://ultralytics.com/images/bus.jpg'
```

能正常运行并输出检测结果，即安装成功。

### 4.5 Mac 用户 / 想装更小体积的同学

- **Mac 用户（必看）：** macOS 没有 NVIDIA CUDA，**不能**用 cu130 命令（会提示找不到匹配的安装包）。请安装默认版（Apple 芯片可用 MPS 加速）：
  ```bash
  pip3 install torch torchvision
  ```
- **Windows / Linux 没有 N 卡、且想省下数 GB 下载：** 可以改装体积更小的 CPU 版（功能完整）：
  ```bash
  pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cpu
  ```
  > 若希望本地环境尽量与课程 GPU 服务器一致，建议仍按 §4.3 装 GPU 版；图省事或磁盘紧张则用本 CPU 版——两者都能通过冒烟测试、都能上课。
- **较老的 NVIDIA 显卡（GTX 10 系列等）想在本地用 GPU：** CUDA 13 不支持，请到 <https://pytorch.org/> 安装向导选 cu126 / cu128 等较低版本的命令。
- 以上任一方式装完 PyTorch 后，再执行 §4.4 安装 ultralytics（**顺序不变：先 torch 后 yolo**）。

## 五、Git 安装与配置（必装）

### 5.1 它是什么

Git 是版本控制工具，用于获取（clone）课程代码仓库、记录你的修改、以及向远程提交作业。

### 5.2 下载安装

1. 下载地址：<https://git-scm.com/install/windows> （或访问 <https://git-scm.com/download/win> 自动开始下载）。
2. 运行安装程序，**绝大多数页面保持默认、一路 Next 即可**。其中几个页面说明：
   - **Select Components**：保持默认。
   - **Choosing the default editor**：新手可选 **Use Notepad as Git's default editor**（用记事本），避免默认的 Vim 不会退出。
   - **Adjusting the name of the initial branch**：可选「Let Git decide」或将默认分支设为 `main`。
   - 其余安全 / 换行符等选项**保持默认**。
3. 完成后点 **Install** → **Finish**。

### 5.3 验证安装

在「开始」菜单搜索打开 **Git Bash**，或在 CMD / PowerShell 中执行：

```bash
git --version
```

显示类似 `git version 2.54.0` 即成功。

### 5.4 必做：配置你的身份信息

首次使用 Git 必须配置用户名和邮箱（会记录在你的每次提交里）。
**请使用真实姓名与学号 / 学校邮箱**，便于助教识别。在 Git Bash 中执行：

```bash
git config --global user.name "你的姓名"
git config --global user.email "你的学号或邮箱@example.com"
git config --global core.autocrlf true
```

验证配置是否写入：

```bash
git config --global --list
```

> `core.autocrlf true` 用于在 Windows 上自动处理换行符，避免跨平台协作时整文件被标记为改动。

## 六、PyCharm 安装与配置（推荐，非强制）

### 6.1 你需要知道的最新变化

从 **2025.1 版起，PyCharm 已合并为统一版本**，不再区分「社区版 / 专业版」：

- **核心功能永久免费**，安装后会自动开启 **30 天 Pro 试用**；试用到期后不付费也能继续使用免费核心功能，设置和项目都不会丢。
- **学生 / 教师福利：** 用**有效的学校邮箱**可在 JetBrains 教育计划免费申请**完整 Pro 授权**。建议先申请：
  <https://www.jetbrains.com/community/education/>

### 6.2 下载安装

1. 下载地址：<https://www.jetbrains.com/pycharm/download/?section=windows> （选择 **Windows** 版本下载）。
2. 运行安装包，安装路径同样**避免中文与空格**。
3. 在 `Installation Options` 页，建议勾选：
   - ✅ Create Desktop Shortcut（创建桌面快捷方式）
   - ✅ Add "Open Folder as Project"（右键用 PyCharm 打开文件夹）
   - 其余可默认。
4. 完成后按提示重启电脑（如有要求）。

### 6.3 关键步骤：把 `odplat` 环境设为项目解释器

这是 PyCharm 能正确运行课程代码的**核心配置**，请务必完成：

1. 打开 PyCharm，新建或打开一个项目文件夹。
2. 进入设置：菜单 **File → Settings**（快捷键 `Ctrl+Alt+S`）。
3. 左侧选择 **Project: ［项目名］ → Python Interpreter**。
4. 点击右上方 **Add Interpreter → Add Local Interpreter…**。
5. 在弹窗左侧选择 **Conda**：
   - **Conda executable**：填入 conda 的可执行文件路径，通常为
     `C:\Users\<用户名>\miniconda3\Scripts\conda.exe`（点右侧文件夹图标浏览选择）。
   - 选择 **Use existing environment**，在下拉中选中 **`odplat`**。
6. 点击 **OK** 应用。等待 PyCharm 索引完成后，右下角解释器应显示为 `Python 3.12 (odplat)`。

> 建议对第 5 步的弹窗**截图存档**。若下拉里找不到 `odplat`，请确认 §3.2 已成功执行，并核对 conda.exe 路径，或参见文末 FAQ。

### 6.4 验证 PyCharm 配置

在项目里新建文件 `hello.py`，输入：

```python
import sys, torch
print("Python:", sys.version)
print("解释器路径:", sys.executable)
print("Torch 版本:", torch.__version__)
print("Torch CUDA 可用（本地有N卡才为True）:", torch.cuda.is_available())
```

右键 **Run 'hello'** 运行。只要能正常打印出 Python 与 Torch 版本、路径包含 `envs\odplat`，即配置成功
（`Torch CUDA 可用` 为 True 或 False 取决于本地有无 N 卡，都不影响）。

### 6.5 其他 IDE 选项（VS Code 用户参考）

若你使用 **VS Code**：安装官方 **Python** 扩展后，按 `Ctrl+Shift+P` → 输入并选择 **Python: Select Interpreter** → 在列表中选择名为 **`odplat`** 的 conda 环境即可。其他编辑器同理，核心都是**将解释器指向 odplat 环境**。

## 八、常见问题与排错（FAQ）

**Q1：普通 CMD/PowerShell 提示「'conda' 不是内部或外部命令」？**
A：属正常情况。请改用「**Anaconda Prompt**」运行 conda 命令；或在安装时勾选过「Add to PATH」、或手动把 Miniconda 的 `Scripts` 目录加入系统环境变量 PATH。

**Q2：PowerShell 里 `conda activate odplat` 报错、无法激活？**
A：先在 Anaconda Prompt 中执行一次 `conda init powershell`，关闭并重新打开 PowerShell 后再试。

**Q3：`conda create` 卡住、很慢或下载失败？**
A：多为网络问题。请按 §2.5 配置国内镜像源后重试；内网 / 代理环境请联系本单位 IT。

**Q4：装 PyTorch 后，`torch.cuda.is_available()` 返回 `False`，要紧吗？**
A：先看你**本地有没有 NVIDIA 显卡**：
- **没有 N 卡（或 Mac）：** 这是**正常的**，不要紧。本课程不在本地训练，只要 torch 能正常导入、通过冒烟测试即可，`False` 不影响上课。
- **有 N 卡却是 `False`：** 再排查——①`nvidia-smi` 右上角 `CUDA Version` 是否 ≥ 13.0（不够就更新驱动）；②是否误装成 cpu 版，可 `pip uninstall -y torch torchvision` 后重装 §4.3；③老显卡（GTX 10 系列及更早）不支持 CUDA 13，见 §4.5。

**Q5：先装了 ultralytics，结果 torch 被装成别的版本了，怎么办？**
A：按正确顺序重装即可：先 `pip uninstall -y torch torchvision`，再执行 §4.3（装指定版本 torch），最后执行 §4.4 安装 ultralytics。

**Q6：Mac 上执行 cu130 命令报「找不到匹配的版本」？**
A：正常——macOS 没有 NVIDIA CUDA 版的 PyTorch。请改用默认版：`pip3 install torch torchvision`（见 §4.5）。

**Q7：`pip install torch ...` 下载很慢或中途中断？**
A：该文件较大（数 GB），建议使用稳定有线网络；中断后重新执行同一条命令即可（pip 有缓存，可续传）。注意这一步直连 PyTorch 官方仓库，**不经过清华 pip 镜像**，属正常现象。

**Q8：PyCharm 解释器下拉里找不到 `odplat`？**
A：①确认 §3.2 已成功创建环境（用 `conda env list` 核对）；②核对填写的 `conda.exe` 路径是否正确；③仍不行时，可改用 **Add Local Interpreter → Conda → Use existing environment** 手动浏览到
`C:\Users\<用户名>\miniconda3\envs\odplat\python.exe`。

**Q9：安装或运行时出现奇怪的路径 / 编码报错？**
A：检查软件安装路径或项目路径中**是否含有中文、空格或特殊字符**，若有请移动到纯英文路径下重试。

**Q10：装的包找不到 / 装到别的环境去了？**
A：操作前先确认命令行前缀是 **`(odplat)`**。装错位置时，重新 `conda activate odplat` 后再装即可。

**Q11：想推倒重来怎么办？**
A：执行 `conda remove -n odplat --all` 删除环境，再从 §3.2 重新开始，无需重装 Miniconda。

## 附录 A：macOS / Linux 用户简要说明

整体流程一致，差异点：

- **Miniconda：** 在 <https://repo.anaconda.com/miniconda/> 下载对应系统安装包
  （macOS 选 `.pkg` 或 `.sh`，Linux 选 `.sh`），按官方说明安装。
- **创建并激活环境命令完全相同：**
  ```bash
  conda create -n odplat python=3.12
  conda activate odplat
  ```
- **PyTorch / YOLO（同样：本地不跑训练，冒烟测试通过即可）：**
  - **macOS**：没有 NVIDIA CUDA，**只能**装默认版（Apple 芯片可用 MPS 加速）：
    `pip3 install torch torchvision`
  - **Linux + NVIDIA 显卡（想本地用 GPU）**：
    `pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu130`
  - **Linux 无 N 卡**：可用上面的 cu130 命令（能装上、能过冒烟测试），或装 CPU 版
    `pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cpu`
  - 之后同样**先 torch 后 yolo**：`pip install ultralytics -U`
- **Git：** macOS 可用 `brew install git` 或 Xcode 命令行工具；Linux 用系统包管理器（如 `sudo apt install git`）。
- **验证、PyCharm 配置：** 与正文一致。
